# Diffusion model implementation on U(1) lattice gauge theory

Project contains the scripts and code used to implement a generative diffusion model to a U(1) lattice gauge theory. 

The training data was generated using a Heatbath algorithm, found in `src/generate_mcmc.py`.

## Pre-requisites
The code uses the [DiffusionModels](https://github.com/DiaaEddinH/DiffusionModels) module to run.
